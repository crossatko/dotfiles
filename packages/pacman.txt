# Repo packages (core/extra/multilib), installed by
# `./install.sh` (stage `packages`) with `pacman -S --needed`. One name per line, `#` starts a comment.
# Every name was checked with `pacman -Si`. All names are in core/extra/multilib. The third-party CachyOS and
# Chaotic-AUR repos are added separately by the `repos` stage; no package here depends on them.
#
# Not packaged, install by hand (install.sh lists these at the end):
#   - Hyprland fork (glass compositing, battlestation only): `hyprland` below is the stock build,
#     the workstation uses it as is. Fork build/install steps live in the fork repo.
#   - Font Awesome 7 Pro (licensed): ~/.local/share/fonts/FontAwesomePro/. Brands/Free come from otf-font-awesome.
#   - Paper Mono (UI/terminal font): ~/.local/share/fonts/ (no package).
#   - GPU drivers (vulkan-radeon / nvidia-utils, lib32-* variants) are machine specific and not listed.
#   - multilib (needed for steam) is enabled by install.sh.
